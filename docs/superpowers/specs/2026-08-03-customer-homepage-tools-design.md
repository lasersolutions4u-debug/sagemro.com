# 客户首页公开工具入口设计

## 目标

把客户首页 WelcomePage 的“公开资源”从“计算工具 + Insights”改成纯工具入口，帮助客户直接进入可操作的行业工具，并把折弯模拟器作为新的主入口。

## 首页展示

桌面端展示一排 4 个工具卡片；平板端为 2 列；手机端为 1 列。卡片沿用 SAGEMRO 现有客户首页的颜色、边框、图标和交互风格，不新增独立视觉体系。

工具顺序固定为：

1. 折弯模拟器
2. 材料重量计算器
3. 激光切割成本估算
4. 钢材价格预算工具

每张卡片直接链接到对应的 `/tools/:slug` 页面；区域保留一个“查看全部工具”入口，指向 `/tools`。

## 明确移除

- 不在客户首页公开资源区域显示 Insights 卡片或 Insights 按钮。
- 不把“V 槽与折弯展开辅助工具”放入首页 4 个卡片中，避免与折弯模拟器产生同类入口重复；该工具继续保留在全部工具页。
- 不删除 Insights 页面、路由或工具详情页，只移除客户首页该区域的入口。

## 验收标准

- 客户首页公开资源区域只出现 4 个工具入口，不出现 Insights 文案或 `/insights` 链接。
- 折弯模拟器入口使用现有工具 slug，并能从首页直接进入。
- 其他 3 个工具链接到现有工具 slug，不新增重复工具数据。
- 桌面、平板、手机布局分别符合 4/2/1 列响应式要求。
- 现有客户首页测试、前端 lint 和构建继续通过。
