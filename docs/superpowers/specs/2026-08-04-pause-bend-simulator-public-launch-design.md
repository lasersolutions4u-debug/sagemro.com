# 暂停折弯模拟器公开发布与首页切割工具替换设计

## 背景

当前折弯模拟器的简化碰撞模型会把部分实际可折工况判定为干涉。该结果不足以作为真实工艺可行性的依据，继续用局部阈值修补会增加客户误判风险。因此暂停其公开发布，等后续具备更可靠的工件姿态、模具空间和连续过程模型后再继续。

## 目标

- 暂停折弯模拟器的客户公开入口，但完整保留现有代码、测试数据和研发分支。
- 客户首页仍展示一排 4 个工具，用“激光切割速度参考”替换“折弯模拟器”。
- 折弯模拟器不再出现在公开工具目录、工具弹窗或其他工具的推荐列表中。
- 保留 `/tools/bend-simulator` 隐藏直达路由，供内部复核和后续继续开发，并设置为 `noindex`。

## 公开界面

客户首页工具顺序固定为：

1. 激光切割速度参考
2. 材料重量计算器
3. 激光切割成本估算
4. 钢材价格预算工具

桌面、平板、手机继续沿用现有 4/2/1 列响应式布局和 SAGEMRO 视觉样式，不新增组件或视觉体系。中英文首页同时替换文案和链接。

## 数据与路由边界

`industryTools` 继续作为完整工具注册表，包含暂停的折弯模拟器，确保隐藏直达路由和现有研发代码不被删除。新增 `publicIndustryTools` 作为客户公开列表，只排除 `bend-simulator`。工具中心、侧边工具弹窗和详情页推荐统一读取公开列表。

`/tools/bend-simulator` 仍能通过完整注册表解析，但页面 SEO 设置为 `noindex,nofollow,noarchive`。现有 sitemap 已不包含该路由，无需修改。

## 明确不做

- 不修正、重写或删除折弯模拟器计算与动画代码。
- 不删除折弯工具相关测试和研发分支。
- 不修改 Worker、数据库、部署流程或 Cloudflare 配置。
- 不新增切割工具；复用已经存在并通过测试的激光切割速度参考。

## 验收标准

- 中英文客户首页都不出现折弯模拟器入口，并显示激光切割速度参考入口。
- 首页仍为 4 个工具，原有其他 3 个工具及顺序保持不变。
- 公开工具中心、工具弹窗和相关工具推荐不出现折弯模拟器。
- 隐藏直达路由仍可解析，且搜索引擎标记为不索引。
- 前端测试、lint 和生产构建通过。
