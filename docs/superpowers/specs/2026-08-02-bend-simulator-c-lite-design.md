# SAGEMRO C-Lite 折弯模拟器设计规格

## 1. 目标与定位

为 SAGEMRO `/tools` 工具体系增加一个面向客户的折弯模拟器。用户可以选择材料、板厚、折弯机参数和通用模具，绘制多段二维折弯轮廓，观看板材成形动画，并获得模具、V 槽、吨位和风险提示。

它首先是一个可玩的规划工具和引流入口，不是生产级 CAD/CAM，也不替代现场试折、机床手册或工程师确认。

## 2. 第一版范围

### 包含

- 结构化材料、板厚、板宽和机型参数输入。
- 多段二维折弯轮廓编辑，支持边长、角度、内 R 和折弯顺序。
- 2D 截面预览与 3D 视觉成形预览。
- 播放、暂停、逐步查看和拖动时间轴。
- 通用机型参数与通用上模/下模库。
- 展开长度、吨位、V 槽和模具匹配的确定性计算。
- 短边、超吨位、余量不足和潜在干涉的风险提示。
- 匿名试算、方案保存/分享和工程师复核线索入口。
- 中文/英文界面，沿用现有 `/tools` SEO 结构。

### 不包含

- DXF、PDF、照片或手绘图识别。
- 孔位、复杂自由曲线、焊缝和完整 3D CAD 建模。
- 真实机床品牌的官方能力承诺。
- 生产级碰撞仿真、回弹预测和自动 CAM 输出。
- 多模态模型参与核心计算。
- 强制登录后才能试算。

## 3. 用户流程

1. 进入 `/tools/bend-simulator`。
2. 选择单位、材料、板厚和板宽。
3. 添加或编辑多个折弯段。
4. 为每段设置边长、角度、内 R 和顺序。
5. 选择通用机型，或输入机器吨位和工作长度。
6. 查看实时模具匹配、吨位和风险提示。
7. 播放折弯动画，按步骤检查成形过程。
8. 调整参数并重新模拟，或保存/分享方案。
9. 需要确认时，将结构化方案提交给 SAGEMRO 工程师。

## 4. 页面结构

页面采用三栏加底部时间轴：

- 左栏 `BendProfileEditor`：材料、板厚、机器、折弯段和顺序编辑。
- 中栏 `BendSimulationViewport`：2D/3D 切换、板材、上下模、尺寸和角度标注。
- 右栏 `BendResultPanel`：推荐上模、V 槽、预计吨位、机器余量和风险。
- 底部 `BendSimulationTimeline`：播放、暂停、上一步、下一步和拖动进度。

移动端按“编辑 → 模拟 → 结果”纵向排列，时间轴固定在模拟区域底部，不要求用户横向滚动整张桌面布局。

## 5. SAGEMRO 视觉规范

模拟器复用 `frontend/src/styles/tokens.css` 和 `frontend/src/index.css` 的设计 token，不建立独立品牌色：

- 主操作、当前步骤和选中状态使用 SAGEMRO Amber `#f59e0b`。
- 页面和卡片使用现有白色、浅灰表面与边框层级。
- 深炭色仅用于侧栏、工具栏或辅助控制区。
- 板材和模具使用钢铁感的灰蓝/中性色，避免引入竞品绿色。
- 绿色只表示通过或推荐，橙色表示需要确认，红色表示风险，蓝色表示信息。
- 复用现有字体、8px 间距网格、圆角、阴影和过渡动画。

## 6. 确定性仿真引擎

核心计算放在独立的 `bendSimulationEngine.js`，不依赖模型 API。输入统一为：

```js
{
  unitSystem,
  material,
  thicknessMm,
  sheetWidthMm,
  machine,
  segments: [{ lengthMm, angleDeg, insideRadiusMm, order }],
  upperTool,
  lowerTool
}
```

引擎输出：

- 标准化二维轮廓和折弯节点。
- 2D 展开/成形几何。
- 3D 视觉渲染所需的姿态序列。
- 折弯补偿和展开长度参考。
- 估算吨位与机器余量。
- 上模、下模和 V 槽匹配结果。
- 短边、超载、余量不足和潜在干涉警告。
- 每一道折弯的动画帧和推荐顺序。

2D 几何是计算的权威来源，3D 只是同一结果的表现层。所有结果必须显示“规划参考”性质，并要求生产前依据实际材料、模具、机床和试折结果校准。

## 7. 机型与模具数据

第一版使用通用参数，不宣称官方品牌精度。机型记录至少包含：

- 额定吨位。
- 最大折弯长度。
- 允许的最小/最大板厚参考。
- 工作台和喉深参考。
- 支持的模具接口类型。

模具记录至少包含：

- 上模类型和尖端半径。
- 下模类型和 V 槽范围。
- 推荐板厚范围。
- 可用角度范围。
- 与机型接口的兼容关系。

数据应从组件中分离，未来可以迁移到 Worker 或 Admin 管理，而无需改动模拟器 UI。

## 8. AI 与后端边界

第一版不接多模态 API，也不让 AI 参与吨位、模具和风险结论。浏览器本地计算保证即时响应。

Worker 后续可提供：

- 方案保存与分享链接。
- 匿名漏斗事件。
- 工程师复核线索。
- 经过用户确认后的自然语言解释。

未来支持 DXF/PDF/照片时，识别结果必须先展示给用户确认，再进入确定性引擎；模型识别不能直接改变生产建议。

## 9. 引流与线索流程

- 用户无需登录即可试算。
- “保存/分享”和“工程师复核”才触发联系方式收集。
- 工程师线索自动附带完整的材料、几何、机型、模具、吨位和风险上下文。
- 结果页同时提供“继续调整”和“重新模拟”，避免把工具变成单纯表单。
- 记录匿名的启动、完成、调整、分享和复核点击事件，不采集不必要的材料或联系人文本。

## 10. 测试与验收

计算测试覆盖：

- 单段和多段轮廓。
- 不同材料、板厚、角度和内 R。
- 吨位和机器余量边界。
- V 槽与上模筛选。
- 短边、超载和潜在干涉警告。
- 折弯顺序与动画帧一致性。

界面测试覆盖：

- 中文/英文切换。
- 2D 编辑和 3D 预览同步。
- 播放、暂停、逐步和拖动时间轴。
- 桌面三栏和移动端纵向布局。
- 结果页复核入口和方案上下文完整性。
- `/tools` 页面 SEO、导航和现有引流路径不回归。

## 11. 分阶段路线

### Phase 1：C-Lite 核心体验

多段二维轮廓、通用机型/模具、确定性计算、2D/3D 视觉动画、风险提示和工程师复核入口。

### Phase 2：数据与分享

方案保存、分享链接、Admin 维护机型/模具数据、匿名漏斗分析。

### Phase 3：文件输入

优先加入可验证的 DXF/PDF 解析；识别结果需要用户确认。

### Phase 4：多模态辅助

最后再加入照片、截图或手绘图识别，以及 AI 对结果的自然语言解释。

## 12. 成功标准

- 用户无需注册即可在几分钟内完成一次多段折弯模拟。
- 结果可以解释“为什么推荐这个模具和 V 槽”。
- 动画、参数和结果始终一致。
- 用户可以一键把方案交给 SAGEMRO 工程师复核。
- 工具保持 SAGEMRO 现有视觉语言，不像独立竞品页面。
- 任何结果都不会被表述为未经校准即可直接生产。
